# Next Steps After Supervisor Acceptance

## Flow Overview

Once a supervisor accepts a student's request, here's what happens next:

---

## ✅ What Happens Automatically

1. **Supervisor Status Changes**: 
   - Status changes from `pending` → `accepted`
   - Evaluation forms are automatically created:
     - Scope Document Evaluation
     - SRS Evaluation (Supervisor & Committee Member)
     - SDD Evaluation (Supervisor & Committee Member)
     - Evaluation 3 (Supervisor & Committee Member)
     - Evaluation 4 (Supervisor & Committee Member)

2. **Student Dashboard Updates**:
   - "Documents" tab becomes available
   - "Chat" tab becomes available
   - Success message appears in Supervisor tab

---

## 📋 Next Steps for Students

### Step 1: Upload Documents

**Location**: Student Dashboard → **Documents** tab

**Available Document Types**:
1. **Scope Document** - Initial project scope and requirements
2. **SRS Document** - Software Requirements Specification
3. **SDD Document** - Software Design Document
4. **Final Report Document** - Final project report
5. **Presentation Document** - Presentation slides

**How to Upload**:
1. Go to Documents tab
2. Select document type from dropdown
3. Click "Choose File" and select your document
4. Document will be uploaded with status "pending"
5. Supervisor can then accept/reject it

**Document Status Flow**:
- `pending` → Student uploads
- `accepted_by_student` → Student confirms (optional)
- `accepted` → Supervisor approves
- `rejected` → Supervisor rejects (student can re-upload)

---

### Step 2: Communicate with Supervisor

**Location**: Student Dashboard → **Chat** tab

**Features**:
- Real-time messaging with supervisor
- Messages are stored and visible to both parties
- Messages auto-refresh every 3 seconds

**How to Use**:
1. Go to Chat tab
2. Type your message
3. Click "Send"
4. Messages appear in chronological order

---

### Step 3: View Supervisor Information

**Location**: Student Dashboard → **Supervisor** tab

**What You Can See**:
- Supervisor name
- Project name
- Request status
- Success message when accepted

---

## 📋 Next Steps for Supervisors

### Step 1: View Assigned Groups

**Location**: Supervisor Dashboard → **My Groups** tab

**What You Can See**:
- List of all accepted student groups
- Project information
- Student names
- Click on a group to see details

---

### Step 2: Review and Evaluate Documents

**Location**: Supervisor Dashboard → **Evaluations** tab

**Evaluation Types**:
1. **SRS Evaluation** - Evaluate Software Requirements Specification
2. **SDD Evaluation** - Evaluate Software Design Document
3. **Evaluation 3** - Mid-project evaluation
4. **Evaluation 4** - Final evaluation

**How to Evaluate**:
1. Go to "My Groups" tab
2. Click on a group card
3. Go to "Evaluations" tab
4. Select evaluation type
5. Fill in criteria (pending, marginal, adequate, good, excellent)
6. Add comments
7. Marks are calculated automatically

---

### Step 3: Review Uploaded Documents

**Location**: Supervisor Dashboard → **My Groups** → Select Group

**What You Can Do**:
- View all documents uploaded by students
- Accept or reject documents
- See document status and upload dates

---

## 📋 Next Steps for Committee Members

### Step 1: Evaluate Projects

**Location**: Committee Member Dashboard → **Evaluations** tab

**Evaluation Types**:
1. **Scope Document Evaluation** - Initial project evaluation
2. **SRS Evaluation** - Requirements evaluation
3. **SDD Evaluation** - Design evaluation
4. **Evaluation 3** - Mid-project evaluation
5. **Evaluation 4** - Final evaluation

---

## 📝 Important Notes

1. **Document Upload**: Students can upload documents only after supervisor is accepted
2. **Document Status**: Documents start as "pending" and need supervisor approval
3. **Chat**: Available 24/7 for communication
4. **Evaluations**: Created automatically when supervisor accepts
5. **Multiple Documents**: Students can upload multiple versions (new uploads replace old ones)

---

## 🐛 Troubleshooting

### Documents Tab Not Showing?
- Check if supervisor status is "accepted"
- Refresh the page
- Check browser console for errors

### Can't Upload Documents?
- Ensure supervisor is accepted
- Check file size and format
- Verify you're in the correct group

### Chat Not Working?
- Check if supervisor is accepted
- Refresh the page
- Check network connection

---

## 📊 Status Indicators

- 🟡 **Pending** - Waiting for action
- 🟢 **Accepted** - Approved
- 🔴 **Rejected** - Needs revision
- ⚪ **Accepted by Student** - Student confirmed

---

## 🚀 Quick Start Checklist

After supervisor accepts:

- [ ] Check Supervisor tab - see acceptance confirmation
- [ ] Go to Documents tab - start uploading documents
- [ ] Upload Scope Document first
- [ ] Use Chat tab to communicate with supervisor
- [ ] Monitor document status
- [ ] Wait for supervisor feedback
- [ ] Upload next document type when ready

---

## 💡 Tips

1. **Start with Scope Document** - Usually the first document to upload
2. **Use Chat for Questions** - Don't hesitate to ask supervisor
3. **Check Status Regularly** - Monitor document approval status
4. **Follow Templates** - Committee members may upload templates
5. **Keep Documents Updated** - Re-upload if rejected
